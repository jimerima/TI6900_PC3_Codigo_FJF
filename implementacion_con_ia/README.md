# Implementación con IA generativa

## Objetivo
Realizar proceso ETL asistido utilizando IA generativa en Google Cloud Data Fusion.

## Flujo
Cloud Storage -> Data Fusion -> Wrangler -> BigQuery

## Fases

1. Perfilamiento asistido del dataset  
2. Limpieza de nulos automatizada  
3. Conversión de tipos sugerida por IA  
4. Validación de IDs optimizada  
5. Carga final  

## Tiempo total

1h 20min

## Bitácora de tiempos por fase

| Fase del proceso        | Implementación 2 (Con IA) |
|------------------------|--------------------------|
| Perfilamiento de datos | 10 min                   |
| Configuración de Stack | 25 min                   |
| Limpieza y transformación | 20 min                |
| Depuración de errores  | 20 min                   |
| Carga final            | 5 min                    |
| **Total**              | **1 h 20 min**           |
