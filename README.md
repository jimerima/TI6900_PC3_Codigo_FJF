# TI6900_PC3_Codigo_FJF
Este repositorio contiene la implementación de un proceso ETL utilizando Google Cloud Data Fusion, comparando dos enfoques:

- Implementación tradicional (sin IA)
- Implementación asistida con IA generativa

# Estructura del repositorio
implementacion_con_ia/: Implementación del proceso ETL asistido con IA generativa

Evidencias/: Imágenes del flujo ETL y transformaciones realizadas

Prompts_principales.txt: Prompts utilizados para asistir el proceso con IA

README.md: Bitácora de tiempos y descripción del proceso con IA

retail_store_sales_limpia.csv: Dataset final limpio generado con IA

---------------------------------------------------------------------------------------------
implementacion_sin_ia/: Implementación del proceso ETL sin uso de IA

Evidencias/: Imágenes del flujo ETL manual

README.md: Bitácora de tiempos y descripción del proceso manual

retail_store_sales_limpia.csv: Dataset final limpio generado manualmente

---------------------------------------------------------------------------------------------
TI6900_PC3_FJF.pdf: Documento formal con la explicación completa del experimento
