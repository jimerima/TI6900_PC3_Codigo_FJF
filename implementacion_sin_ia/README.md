# Implementación sin IA generativa

## Objetivo
Realizar proceso ETL manual utilizando Google Cloud Data Fusion.

## Flujo
Cloud Storage -> Data Fusion -> Wrangler -> BigQuery

## Fases

1. Perfilamiento manual del dataset
2. Limpieza de nulos
3. Conversión de tipos
4. Validación de IDs
5. Carga final

## Tiempo total

2h 25min

## Bitácora de tiempos por fase

| Fase del proceso | Implementación 1 (Sin IA) |
|------------------|--------------------------|
| Perfilamiento de datos | 20 min |
| Configuración de Stack | 35 min |
| Limpieza y transformación | 35 min |
| Depuración de errores | 50 min |
| Carga final | 5 min |
| **Total** | **2 h 25 min** |
